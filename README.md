# Campus IT Infrastructure & Operations Portfolio

A comprehensive operational record and technical case studies managing campus-wide IT systems, network infrastructure, and security surveillance at Bintang Pelajar Islamic Boarding School.

---

## 📌 Overview

This repository documents production-grade implementations, troubleshooting reports, and infrastructure architecture designs executed across campus environments. It demonstrates hands-on competencies in network administration, server virtualization, reverse proxy implementations, and enterprise CCTV infrastructure.

---

## 🛠️ Core Tech Stack & Scope

* **Networking & Routing:** MikroTik RouterOS, Ubiquiti UniFi, Multi-WAN Failover, VLAN segmentation.
* **Systems & Virtualization:** Linux (Ubuntu/Debian), Hyper-V, Proxmox VE, Reverse Proxy & SSL integration.
* **Surveillance & IoT:** Dahua WizSense Ecosystem, SmartPSS Lite, Multi-DVR management (98+ channels).
* **Infrastructure Operations:** End-to-end troubleshooting, maintenance SOPs, and service uptime continuity.
